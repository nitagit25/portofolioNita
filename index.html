void loop() {
  uint16_t range = tofSensor.readRangeContinuousMillimeters();
  if (range <= SAFE_THRESHOLD_MM) {
    robotState = STATE_AVOID_OBSTACLE;
    executePivotTurn(DIR_RIGHT, SPEED_REDUCED);
  } else {
    robotState = STATE_MOVE_FORWARD;

  }
}

Tentang Saya

Mahasiswa Teknik Komputer yang Berfokus pada Sistem Robotika 🎀

Saya adalah mahasiswa tingkat sarjana terapan (D4) Teknik Komputer di Politeknik Elektronika Negeri Surabaya (PENS) dengan minat mendalam pada pemrograman sistem robotika dan integrasi hardware-software. Fokus utama saya terletak pada perancangan logika kendali tingkat mikrokontroler: mulai dari akuisisi data sensor, pemfilteran dan pemrosesan sinyal masukan, hingga pengondisian sinyal kendali PWM untuk menggerakkan aktuator secara presisi.

Dalam implementasi praktis, saya menggunakan bahasa C/C++ pada mikrokontroler ESP32 dan Arduino Uno, serta memanfaatkan Python dan simulasi Proteus / KiCad untuk verifikasi awal rancangan sirkuit kendali.

Saya senang memecahkan tantangan teknis yang berada di perbatasan antara dunia digital dan fisik—seperti mengatasi pembacaan sensor yang bising (noisy), sinkronisasi waktu eksekusi program (timing), dan penanganan galat gerak mekanis melalui logika program yang adaptif. Target karier saya adalah berkontribusi sebagai Robotics Programmer atau Software Engineer pada pengembangan sistem robot bergerak dan otomasi industri yang mengutamakan keandalan kendali berbasis waktu nyata.

Featured Project #1 🌸 ESP32 VL53L0X ToF (I2C) C / C++
Embedded Robotics ✨

Robot Navigasi Sensor Jarak Berbasis ESP32 & Sensor Laser ToF VL53L0X

Sistem mobile robot beroda dua yang memproses data jarak spasial secara real-time menggunakan protokol komunikasi I2C dari sensor laser Time-of-Flight VL53L0X untuk menentukan keputusan navigasi manuver menghindar rintangan.

Problem or Objective 💡

Sensor ultrasonik konvensional rentan terhadap pantulan sudut miring dan distorsi material lunak. Proyek ini bertujuan mengintegrasikan sensor laser Time-of-Flight VL53L0X yang memiliki presisi tinggi pada ESP32, lalu memetakan data jaraknya ke logika kendali PWM motor DC untuk navigasi penghindaran benturan secara deterministik.

System Architecture & Hardware ⚙️

Sensor: VL53L0X ToF (I2C Bus: SDA/SCL) Controller: ESP32 DevKit V1 (3.3V Logic) Driver: Dual H-Bridge Motor Driver Aktuator: 2x DC Gearbox Motor + Caster Power: Li-ion Battery Pack

Programming Logic & Integration 💻

  • Akuisisi I2C: Menginisialisasi komunikasi I2C pada clock 400kHz dengan polling kontinu nilai range dalam satuan milimeter.
  • Threshold Decision: Jika jarak terdeteksi > ambang aman, sistem menjaga duty-cycle PWM maju lurus. Jika jarak ≤ batas kritis, sistem mengaktifkan rutinitas pivot manuver (satu roda mundur, satu roda maju) hingga area bebas rintangan kembali tercapai.
  • Error Handling: Menambahkan verifikasi status data I2C untuk mencegah robot 'macet' apabila sensor mengalami timeout atau pembacaan out-of-range.

Kontribusi Pribadi (My Role) 🎀

Bertanggung jawab penuh atas penulisan firmware kendali C/C++, konfigurasi bus I2C pada ESP32, implementasi logika evaluasi jarak, kalibrasi sinyal PWM motor driver, dan debugging kestabilan komunikasi serial.

Hasil & Pengujian (Testing & Results) ✨

  • Hasil Uji: Robot berhasil mendeteksi objek padat pada jarak ambang uji dan mengeksekusi belokan tanpa tabrakan fisik pada rentang kecepatan rendah-menengah.
  • Kendala: Drop tegangan sesaat saat motor mulai menyala (*inrush current*) sempat mereset modul I2C sensor.
  • Solusi: Memasang kapasitor decoupling pada jalur 3.3V dan memastikan jalur daya motor terisolasi dari rel daya ESP32.

Featured Project #3 🌸 IR Sensor Array ATmega / Arduino PWM Steering
Autonomous Line Follower ✨

Robot Pengikut Lintasan Garis Berbasis Pembacaan Sensor Optik

Mobile robot otonom beroda dua yang secara adaptif membaca kontras garis pandu permukaan menggunakan barisan sensor inframerah dan melakukan koreksi kemudi melalui modulasi PWM motor secara kontinu.

Problem or Objective 💡

Membangun sistem kendali kemudi tertutup (*closed-loop corrective steering*) yang mampu merespons tikungan lintasan tanpa terlempar keluar dari garis akibat inersia mekanik robot.

System Architecture & Hardware ⚙️

Sensor: Array Fotodiode & Komparator Op-Amp MCU: Arduino Uno (ATmega328P) Driver: L298N Dual H-Bridge Motor: 2x DC Motor 6V with Rubber Tires

Programming Logic & Decision Matrix 💻

  • Bitmasking Sensor: Memetakan sinyal logika sensor biner (misal `0b010` = lurus, `0b100` = belok tajam kiri, `0b001` = belok tajam kanan).
  • Differential PWM Tuning: Menghitung perbedaan duty-cycle motor kiri dan motor kanan untuk menghasilkan radius putar yang proporsional dengan kelengkungan tikungan.

Kontribusi Pribadi (My Role) 🎀

Perakitan dan kalibrasi trimpot ambang tegangan sensor garis, penulisan program kendali arah di Arduino IDE, penentuan tabel logika keputusan, serta pengujian stabilitas di berbagai kecepatan PWM.

Hasil & Pengujian (Testing & Results) ✨

  • Hasil Uji: Robot berhasil melintasi jalur garis berkelok secara stabil pada kecepatan uji yang telah dikalibrasi.
  • Kendala: Terjadi osilasi (robot bergoyang ke kiri-kanan) saat memasuki trek lurus berkecepatan tinggi.
  • Solusi: Memperkecil deviasi diferensial PWM saat hanya sensor tengah yang aktif.
